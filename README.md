# 校园会员店 · 0.5.2

**本项目完全由codex完成**

简洁查看校园超市会员价与特惠，支持门店切换、名称搜索、商品大类/小类、价格与优惠组合筛选、8 种排序及自动继续加载。

## 安卓怎么用

1. 下载 `android/campus-market-0.5.2.apk`，在 Android 8.0 及以上手机允许安装。已有本软件时可覆盖更新，保留登录状态。
2. 首次连接前，先安装并登录天猫校园。
3. 本软件会员页点“连接／切换自己的账号”，再点“跳转天猫校园授权”。由本人在官方确认页允许登录，返回后自动验证并连接。
4. 日常直接打开本软件显示、刷新自己的会员码；无需电脑、截图扫码或反复跳转。登录状态加密保存在各自手机上，安装包不带任何人的账号。
5. 商品页选择超市，按分类、小类、搜索或抽屉里的价格、优惠、排序检索。每批 60 件，向下滚动继续加载。

若授权页尚未准备好，可稍候重试；首次授权需要原 App 和网络。服务器使会话失效、清除应用数据或更换手机后需要重新授权，不保证永久登录。不同版本原 App 可能改变授权入口。

## 网页怎么用

**当前网页支持商品浏览，不支持个人会员码登录。** 网页与安卓不能共享登录状态，会员码请使用安卓版本。网页版目前没有长期在线地址。

安装 Node.js 22 或更高版本，在仓库目录运行：

```sh
node web/start.mjs
```

浏览器打开 <http://localhost:8080/>。不需要安装 npm 依赖，也不需要连接手机。停止服务按 Ctrl+C。

手机通过网页长期使用时，需要将 `web/` 部署在持续运行的服务器上并配置 HTTPS。仅上传 GitHub 文件或开启 GitHub Pages，不能代替这里的商品服务。

端口默认 8080，可用 `PORT` 环境变量修改。若通过 HTTPS 域名和反向代理访问，请同时设置对外的 `PUBLIC_ORIGIN`，例如 PowerShell：

```powershell
$env:PORT='8080'
$env:PUBLIC_ORIGIN='https://你的域名'
node web/start.mjs
```

`PUBLIC_ORIGIN` 填协议和域名，不带路径；代理转发到 Node 服务端口。Cloudflare Workers 等兼容环境也可以使用 `web/worker.mjs` 的默认 `fetch` 导出，需要支持服务端 fetch 与 Set-Cookie 读取；发布前自行验证目标环境。

## 已验证与限制

- 当前开发手机：三店读取、返回键关闭弹层、会员码刷新/放大同步、重启保留登录及本人官方授权后直连获取均已验证。
- 尚未使用第二个真实账号及所有安卓机型做交叉验证。
- 商品是服务器已返回的会员价/特惠目录，不能保证包含全部普通商品；名称自动分类可能有偏差，价格和优惠以结算为准。
- 本项目为个人练习工具，与天猫校园官方无隶属关系。未指定自有代码的开源许可证；第三方组件按随附许可证分发。

## 如何更新

安卓：从同一发布来源下载新 APK 并覆盖安装，避免先卸载导致登录数据被清除。

网页：替换 `web/` 中的运行文件，停止并重新启动 Node 服务，再刷新浏览器。更新前后保持一致的部署域名。
